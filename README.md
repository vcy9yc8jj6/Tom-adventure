# 土豆星事件簿 V0.2（Tom Adventure）

这是一个**原创、完全静态、免依赖**的 iPad/手机数学漫画挑战原型。显示名称是《土豆星事件簿》，仓库不需改名。

## 文件
- `index.html`：页面框架
- `styles.css`：主题样式、响应式布局
- `questions.js`：22 道经过人工核算的示例/变式题（不含儿童个人信息）
- `app.js`：轻量训练引擎、本地记录、备份/恢复与换肤

这四个文件放在 GitHub 仓库 `vcy9yc8jj6/Tom-adventure` 的 `main` 分支根目录，GitHub Pages 保持 `Deploy from a branch → main → /(root)`。无需安装软件、无需打包构建、无需外部 API。

## 教学与数据约束
- 每轮最多 5 题；按知识点安排不同变式，避免原题死记。
- 只在**没有查看提示并且首次答对**时计为独立成功。
- 同一知识点在至少 **3 个不同日期**有独立成功，且涉及至少 **2 道不同变式**，才标记为基本掌握；复习间隔依次为 1、3、7、14 天。
- 答错、查看解析或跳过：次日继续安排相关变式；只是学习安排，不给孩子贴“失败”标签。
- 两套外观（《土豆星事件簿》《火柴人行动》）共用同一个题库和学习记录。
- 学习记录、首答、提示次数、重试次数和粗略前台停留秒数保存在浏览器 `localStorage`，不会上传云端；在不同设备间**不会自动同步**。浏览器清理数据会有丢失风险。
- 尝试迁移早期原型 `tom-adventure-v1` 的历史记录。旧版“首次正确”指标可能统计不严，故保留作历史备份而不用于新版掌握判断。
- 公开仓库不可存放孩子姓名、学校、照片或私人答题记录。
- 家长入口**没有认证**，不是安全的私密后台，仅供演示和手动导入导出。
