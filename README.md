## 实现

- 每日常规五题；专题三题和每日完成后的三题自由练习自愿参与。验证题不占每日五题名额。
- 五类参数题：外星运算、连续倍数、已知较轻假币、单次倒水、环形追踪；支持正向与反向提问。参数限制保证数值有限、约束自洽、答案唯一。
- 答错后按题型追问条件、关系及检查，不立即显示答案。第三次错误或第三次提示后才允许主动打开解析。
- 互动公式随机挖空；打开公式或检查公式都计为辅助，不计首次独立掌握。
- 做完后可自愿换一题无提示独立验证。隐藏提示、公式与解析，要求填写手算关键等式；首次正确才能计入独立验证。网页只核对最终数值，手算文字供家长复核，不宣称自动判断书写过程或阻止外部帮助。
- 分步保存答案、提示、公式输入、手算和自选错因；支持刷新恢复当前题及尝试次数。
- 保留双皮肤、本地历史、导入导出功能；新增手机触控与窄屏布局修复。
- `geometryBoard` / `data-api="svg-board-v1"` 预留几何 SVG 挂载容器，尚无几何画板。
