# Tom's Universe · 土豆星事件簿 V0.4（冒险地图与学习记录底座）

这是仅用于静态 GitHub Pages 的六文件网站，尚未部署。部署仓库只能是 `vcy9yc8jj6/Tom-adventure`，保持 `main` 根目录；不涉及其他项目。

## 这一版实现了什么

- **线性故事、非线性复习**：首页出现五个章节节点组成的每日航线，动态选取尚未接触或到期需要复习的题型，而不是把知识点固定在地图上。主线最多五题；到期不足时不为了凑五题强制拿已经掌握的题；完成后有一题可选彩蛋。
- **稍难一点的 BOSS**：主线题量足够时最后一关、三关悬赏的第三关增加自由解释文本框。文字原样保存在本机档案，标记 `reasonAssessment: "unreviewed"`；**不会自动判定解释是否正确、没有接入 AI**。数值答案仍按原本的确定性规则判题。
- **机关注解维修站**：同一类型近十四天内多次出现错误时，首页可进入非计分的知识维修任务。按概念解释 + 小选择机关讲基本原理；不增加今日题数，不凭维修站正确判断掌握；同日已进入过的知识类型不再次自动推荐。
- **剧情与提示分离**：只有每天首次进入任务时可能自动出现一次搞笑剧情，不再每题弹出，更**不计作辅助提示**。主动求助、进入维修站或看解析才算辅助；首次独立答对不会强制「再挑战一次」。
- **低频复习调度**：以知识题型统计首次正确、错答、求助和不同日期的独立验证；独立完成可推进复习阶段（约 1、3、7、14 天）。已掌握的知识点不会每天为了凑数而回归，使用过辅助不会延后到期日。
- **小奖励与界面**：章节地图、人物吐槽、独立验证、每天每个题型首次独立成功的有限金币；支线悬赏折叠收纳，家长导入导出工具收纳在高级选项中。保留原有两种皮肤。

## 学习数据 / 限制

- 本地数据键仍是 `tom-secret-quests-v02`，未修改容器的 `version: 2` 兼容格式；保留历史记录、旧版备份、题包和主题。新增 `journey` 和 `lessons` 字段；升级不要求清除 Safari 数据。开新版本之前仍建议家长先手动导出一次备份。
- 记录 `firstCorrect` 表示无提示且该次第一答数值正确，不代表自由解释经过人工或 AI 审核。手算文字目前只要求填写，不自动检验过程数学是否正确。
- 真正的 AI 动态出题、听懂口语解释、自动同步个人 Google Drive、金币兑换皮肤/招募伙伴、每周更换限制和完整互动几何画板**尚未实现**。不应对儿童宣称 AI 已经能听懂解释。
- 公开 GitHub 仓库只包含代码、固定示例题。儿童学习记录在本机浏览器，不应上传至仓库；没有云端家长认证，家长工具仍为非密码保护演示。

## 本地验收

- `node --check app.js questions.js variants.js`：语法检查。
- `node qa_math.js`：6000 次参数题数学独立核验（5 题型 × 3 难度 × 400 次）。
- `python qa_real.py`：Chromium 通过 320 / 390 / 768 / 1024 px 响应式模拟、剧情与提示区别、首答状态、求助后新题验证、五题和三题流程、自由解释留档、维修站、存档结构兼容和模拟刷新恢复，共 11 组检查。
- **测试限制**：由于当前环境限制浏览器访问 localhost，浏览器测试采用内联同源模拟页面与隔离的 localStorage 模拟器；不是 GitHub Pages 线上验收，也不是 Safari 真机验证。
