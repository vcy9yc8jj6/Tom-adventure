# 土豆星事件簿 V0.3.1｜悬赏与线索交互优化

此包是**待部署源码**，不是已上线证明。以用户报告为准：线上此前为 V0.3，提交 `05cd29d`（六文件）和 `119efde`（缓存修正）；V0.3.1 未提交、未部署、未经过真实 iOS Safari 测试。

## V0.3.1 的新交互

- 首页将五类参数题改成可直接领取的「宇宙悬赏榜」活动卡片，取消了专题/难度下拉框作为儿童主入口；每次悬赏有三关，并有小剧情与前往下一关的鼓励。
- 新增「未解决事件」：从本机既有答题记录推断需要再练的题型；帮助后答对、跳过、查看完整解法的题型可进入此区。独立验证成功后，可从未解决列表撤下。继续调查时生成**相同知识点的新数字**，避免直接背答案。
- 做题先看到完整题目；点「读完了，领取线索」后才打开小熊的思路卡片；关闭后显示作答区。思路卡片不泄漏最后数字或等式答案，并计入辅助记录。
- 回答错误立刻出现明显反馈，保留输入可订正；「求一条线索」按所选卡点（理解条件、建立关系、运算顺序、公式理解、计算失误、单位/检查）返回对应的教学引导。
- 旧版直接显示公式和对应数值的挖空区，替换为**思路工坊**：先讲概念，再做简短互动选择；不在主答题页直接列出最终关系式或答案。
- 「看看怎么解」替换为分层展开的「一步步拆线索」，逐步讲方法，最后单独确认才展示完整演算。看过完整演算记为 assisted/explained，不会当做独立解出。
- 「换题·无提示独立手算验证」缩短为「再挑战一次」，仍生成不同参数题，隐藏辅助并要求填写关键过程。
- 优化 320、390、768px 视口布局，保留土豆星/火柴人两种外观。
- 第三关增加不同于第二关的参数问题（外星运算嵌套、数列反求间隔、天平比较分辨能力、水桶反求原始量；环形追踪反向相遇），提升阶梯感。

## 学习记录与兼容

- 沿用旧版 `tom-secret-quests-v02` 本地存储键、`version:2` 数据容器、已有历史和自定义题库，当前轮存储键后缀仍为 `-session-v03`。
- V0.3.1 没有执行升级清空或重命名动作；之前的记录不会主动消失。正式部署之前仍建议家长用「家长入口 → 导出完整备份」留一份本机备份。
- **看过开场思路卡片的正确作答不计独立掌握**。只有无提示新题的首答正确才作为独立验证依据；独立验证过程中不能看思路卡、工坊或分层解析。
- 辅助下初次答对不会抹掉此前已经独立验证的掌握状态；若出现错误、跳过或需要最终完整解法则会降低该题型的复习状态。
- 无云同步，妈妈手机与 Tom 的 iPad 使用不同浏览器数据；不要把妈妈测试记录当成孩子成绩。

## 本地测试（隔离的合成数据）

- Node `--check` 检查所有 JS 文件语法。
- 独立算术校验 6,000 道参数变式：5 类 × 3 阶 × 400 组，结果一致。
- Chromium DOM 浏览器脚本：320×700、390×844、768×1024 三个视口验证首页、读题、开场思路线索、错题反馈、按卡点求助、分层解析、独立验证、换肤、错误记录清除逻辑；没有横向溢出，未捕获 JS 异常。
- 五题主线、五个不同知识点、完成后自由探索三题、刷新恢复未交卷的答案和练习记录，均在同一类隔离 Chromium 测试中通过。
- 因当前运行环境限制真实 HTTP / file 页面导航，Chromium 测试使用**内联同源模拟页面和临时 localStorage 模拟器**；这是功能逻辑与视觉回归测试，不等于真实 GitHub Pages 或 iOS Safari 验收。

## 已知范围限制

- 三关「夺宝」目前是剧情和题型难度递进；还没有完整的长期专题自动晋级、道具背包、随机倒计时奖励、人物升级及动画系统。
- 概念互动目前是简短选择式机关，不是任意公式的可视化拖拽拼接；卡点提示为各题型预设规则，不是实时 AI 教师。
- 自由文本手算过程只记录，不会自动检查过程数学是否正确。
- 几何 SVG 容器仍是架构预留，没有真实几何工具。
- 无云同步或家长登录鉴权。不能把儿童个人资料或学习记录提交至公开仓库。
