# 土豆星事件簿 V0.4｜星际故事地图（本地预览版）

项目隔离：**只用于 Tom's Universe**。唯一允许发布的仓库为 https://github.com/vcy9yc8jj6/Tom-adventure 。与任何工作项目、工作云盘完全分开。

## 本轮实际实现

- **星际闯关地图**：五个故事节点（当天到期题不足时会缩短），最终节点为小 BOSS。故事按章节轮换，五大知识领域按错题记录和复习日期动态挑选，不将数列、称重、运算等知识错误地锁死到某一固定章节。
- **BOSS 自由解释**：BOSS 除独立答案外可输入自己的理由。系统保存原文、时间、题型、题目和步骤，标记 `reasonAssessment: "unreviewed"`，**目前没有 AI 评阅或实时追问**；答案判对不代表文字解释已验证。
- **机关维修站**：同题连续出错可进入独立教学场景；当同领域近期反复犯错，首页也提示维修邀请。维修选择反馈单独存入 `state.lessons`，不计正式题数，也不自动证明知识掌握；从题目进入时会正确标记为使用过辅助。
- **提示统计修复**：每日开场是一段幽默剧情而非讲题提示；看过剧情不计入 `hints`。开场每天最多自动出现一次；答题时请求线索才算辅助。
- **首次无提示做对**：不再显示多余的「再挑战一次」。无提示首次独立正确是一条有效证据；至少不同三天、两个变式正确才设 `mastered` 并拉长复习间隔。看过提示或错题，会缩短间隔；尚未到期的题**不会为了凑五题自动重复**。
- **金币雏形**：每个知识领域每天首次无提示答对最多获得 2 金币；不会通过重复刷题无限积累。目前只能累计，**皮肤购买、招募队员、每周限制尚未实现**。
- **家长设置**：备份与导入折叠进“进阶管理”，保留本地备份以应对浏览器数据丢失。
- **兼容已有数据**：保留 V0.2 / V0.3 原存储键 `tom-secret-quests-v02` 和会话键 `tom-secret-quests-v02-session-v03`；新字段可增量初始化。不上传实际儿童记录到 GitHub。

## 本地校验

- Node JavaScript 语法检测通过。
- 5 类 × 3 难度 × 1,000 变式，共 **15,000 道**数值答案与参数边界独立核对通过。
- 内联 DOM 测试环境下 Chrome/Chromium 视口 390×844、768×1024、1024×768：地图、开场、答题、错误反馈、卡点线索能操作且无捕获的 JS 异常。
- 同一内联 Chromium 临时存储模拟环境中，五题主线完成、开场不计提示、正常独立答对、BOSS 理由保存、复习进度与金币更新、两次错误后进入维修站、返回原题以及维修不计题数通过。
- **注意**：受当前环境限制，上述测试通过 `page.set_content` 内联页面加内存 localStorage 模拟，并非真实 iOS Safari / GitHub Pages 线上验收。请 Work 部署后再验收。

## 明确未实现

**暂未连接任何 AI 服务**，不会在 iPad 网页里实时判断 Tom 的长篇自然语言解释；更不会把孩子的文字答案自动上传给 ChatGPT。未来 AI 需要安全后台、家长同意、身份验证、API 代理、最少数据与成本上限；绝不可将密钥写入 GitHub Pages 公共 JS。未来待实现语音解释、文字语义追问、跨设备同步、自动云备份、周限制皮肤与伙伴招募、正式几何互动板、可扩展的章节剧情数据库。

## 部署方式

先在设备上**手动备份重要学习记录**。然后将六文件纯部署包上传指定仓库 `main` 根目录，保持 Pages 从 `main` → `/` 发布；不要上传测试图片、家长记录或备份数据。部署后重点测试：新地图能进关卡，刷新后能续答，开场不计提示，五题、维修站、自由理由、错题调度、换肤均正常。只能由授权的 Work 云端浏览器通过 GitHub 网页上传，不使用已返回 403 的 GitHub 插件写入接口。未完成部署前，V0.4 仍仅为本地预览。
